# Channel branding: profile pictures and bios

Profile pictures are the PNGs in this folder (1024x1024, one per account set). `preview_circles.png` shows how each looks cropped to a circle, large and small. To redraw them: `python branding/make_images.py`.

Instagram bio lengths were counted with Python `len()` (limit 150). Emoji count as 1 here, but some apps count them as 2, so every bio leaves room to spare.
